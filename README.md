# WhatsApp Clone

Projeto desenvolvido em React Native com Expo, simulando uma interface de conversas estilo WhatsApp.

## Como rodar o projeto

1. **Instale as dependências:**
   ```bash
   npm install
   ```

2. **Inicie o projeto:**
   ```bash
   npx expo start
   ```

3. **Para testar:**
   - **No celular:** Baixe o app **Expo Go** e escaneie o QR Code que vai aparecer no terminal.
   - **No navegador:** Pressione `w` no terminal para abrir no modo web.
   - **No emulador Android:** Pressione `a` no terminal (com o emulador já aberto).

---

## Tecnologias utilizadas
- React Native
- Expo
- React Navigation (Native Stack)
